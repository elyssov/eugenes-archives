Chapter 10: What To Send

Do not send a motivational essay.

Send proof.

Useful proof includes: playable builds; code repositories; animation sheets; monster designs; painted backgrounds; sprite cleanup packs; combat prototypes; sound reels; UI flows; level paintovers; tactical rules work; QA reports that actually find the lie; anything that shows taste, craft, and the ability to finish.

If all you have is one great thing, send the one great thing.

The workshop can forgive a small portfolio.

It cannot forgive rubber.
